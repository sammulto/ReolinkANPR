# Vehicle classification models

Place any optional vehicle make/model classification artifacts here. The system will enable make/model recognition when compatible model files are present.

Typical files (examples):
- `compcars_resnet50.pth` — PyTorch weights
- `compcars_labels.txt` — One label per line

If no models are available the service will still run: color detection and plate OCR continue to work. See `VEHICLE_MODEL_UPGRADE.md` or `COMPCARS_SETUP.md` for advanced setup and training instructions.
